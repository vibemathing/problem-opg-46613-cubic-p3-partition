# Web GPT + GitHub Mathematical Research Operating Model

This repository is a self-contained single-problem workspace. The GitHub plugin is a candidate generator and transport writer within a machine-enforced path allowlist. It may coordinate through Issues and complete candidate branch/PR/check/merge operations when actual permissions are verified, but it cannot create mathematical Evidence or Results.

Research proceeds in bounded steps over one admitted Obligation. The immutable layers are the ProblemContract, Harness snapshot, schemas, verifier registry, and existing append-only truth records. The mutable Web layer contains only bounded candidate packets, mathematical drafts, source notes, and checkpoint proposals.

Independent local/CI verifiers may consume frozen candidates and emit receipts. A trusted importer checks identities, digests, provenance, verifier independence, statement faithfulness, and Obligation DAG closure before appending EvidenceLinks or deriving a Result.

The local multi-worker/compute-node solution is separate. No compute host, tmux session, GPU service, local credential, or other repository is required to understand and audit this Web workspace.
